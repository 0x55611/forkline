# forks

**Open-source lineage, one fork at a time.**

`forks` is an experimental project exploring the family tree of open-source code:
every repository is a fork of something, and every fork carries a lineage worth
tracing.

This repository is the home of the project and of its community token.

---

## What is this

- A **fork graph** experiment: mapping how projects descend from one another.
- An **open notebook**: notes, tooling and ideas around forks, lineage and attribution.
- A **community token** launched on pump.fun, tied to this repository.

> The token is a community experiment. It is not an investment, it has no
> intrinsic value, and it is not endorsed by any project whose code is
> referenced here.
